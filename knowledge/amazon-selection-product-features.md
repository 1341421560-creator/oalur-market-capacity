# 亚马逊选品规则：产品特色的度量标准

> 来源：第九章 产品特色的度量标准（视频课程）
> 整理时间：2026-06-20

---

## 一、产品特色的核心地位

产品特色是**选品中最重要的环节**。

**核心视角**：
- 开发关注产品的**使用价值**（功能体现）
- 运营关注产品的**商业价值**（市场放大）
- 选品阶段应优先关注使用价值，而非市场数据

---

## 二、产品特色的四大维度

### 1. 单价

**判断标准**：毛利空间是否有弹性（25%-50%）

**价格区间分析**：
| 价格分布 | 含义 | 策略 |
|---|---|---|
| 区间窄 | 产品同质化严重，可延伸性弱 | 只能靠成本控制竞争 |
| 区间宽（高/中/低价位并存） | 产品有迭代空间 | **更理想**，可通过差异化支撑更高售价 |

**差异化路径**：改变材质（碳钢→304不锈钢）、增加配件（磨刀石、收纳袋）→ 支撑更高售价

### 2. 功能（最复杂）

**核心原则**：用户购买产品最看重**功能性**，反馈也多围绕功能。

**分析步骤**：
1. **识别主功能**：产品最核心的功能是什么？
2. **判断主功能是否可变**：迭代是否改变/增强/削弱了主功能？
3. **评估新增功能**：是否实用？是否与主功能场景兼容？是否引发新问题？

**案例**：
- 压蒜器 A→B：外观改变但主功能（压蒜）未变 → OK
- 压蒜器 C：增加压姜功能但主功能空间变小 → 削弱核心体验，需谨慎

**关键**：主功能不可感知的产品（如浴袍柔软度），必须通过材料/填充物的内在改变，并在图片中**可视化展示**出来

### 3. 外观（颜色 + 尺寸）

**颜色**：
- 许多产品的核心卖点
- 对尺寸固定的刚需产品（如袜子），颜色是影响购买的主要外观因素

**尺寸**：
- 长度、宽度、高度、厚度、形状、样式的变化
- 判断：尺寸是否是主要功能？能否满足用户次要需求？

**案例**：
- 午餐包：用户首要关注**容量**（尺寸）→ 先分析尺寸对销量的影响，再考虑颜色
- 办公收纳：通过改变层数、增加笔槽 → 满足不同收纳需求

### 4. 组合（数量增减 + 配件搭配）

**数量增减**：
- 必须基于主功能和用户偏好
- 需平衡数量与成本、质量

**配件搭配**：
- **核心原则**：配件必须对主产品功能起到**补充或增强**作用
- **呈现原则**：主产品必须占据最主要、最突出的地位
- **反面案例**：修眉刀搭配过多不相关配件（指甲钳、挖耳勺）→ 主产品被淹没

## 三、标品 vs 非标品策略

| | 非标品 | 标品 |
|---|---|---|
| **核心需求** | 视觉 > 功能 | 功能 > 一切 |
| **典型品类** | 服饰、装饰品、玩具 | 工具、水杯 |
| **用户偏好** | 变化大，难以量化 | 受众精准或广泛 |
| **推广方式** | 站外为主（Facebook、Instagram、Pinterest） | 站内报品为主 |
| **调研重点** | 设计趋势、审美判断 | 功能展示、量化分析 |
| **注意** | 需深入研究细分品类 | 关键在能否将外显功能通过图片直观展示 |

---

## 四、产品特色的实践意义

- **前期调研**：补充市场数据之外的产品使用价值视角
- **后期迭代**：前期分析的"哪些点可以改变" → 后期产品迭代方向的灵感来源

---

## 五、决策清单

- [ ] 目标产品的价格区间分布是宽还是窄？
- [ ] 毛利空间是否有 25%-50% 的弹性？
- [ ] 是否识别了产品的主功能？
- [ ] 主功能是否可变？迭代是否削弱了主功能？
- [ ] 新增功能是否实用且与主功能兼容？
- [ ] 主功能不可感知的产品，是否有可视化展示方案？
- [ ] 颜色和尺寸中，哪个是该品类的主要外观因素？
- [ ] 组合搭配中，主产品是否占据最突出地位？
- [ ] 配件是否增强了主功能而非喧宾夺主？
- [ ] 该品类是标品还是非标品？调研策略是否匹配？

## 六、核心金句

1. "开发体现产品的使用价值，运营放大产品的商业价值"
2. "用户购买产品最看重功能性，反馈也多围绕功能"
3. "主功能不可感知的产品，必须通过内在改变并可视化展示"
4. "配件必须增强主功能，不能喧宾夺主"
5. "价格区间宽 = 产品有迭代空间，是更理想的选择"
