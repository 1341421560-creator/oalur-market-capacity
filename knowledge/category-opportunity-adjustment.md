# Amazon 选品行业调整系数标准

> 文件用途：用于 Codex / 选品知识库中的 `category-opportunity-adjustment` 标准。  
> 适用场景：在基础机会指数计算完成后，根据类目本身的竞争强度、同质化、广告压力、合规风险、退货风险、季节性等因素，对结果进行保守修正。

---

## 1. 核心定义

**行业调整系数**不是用来判断市场容量大小，而是用来判断：

> 同样的基础机会指数，在不同类目下是否需要打折或加权。

推荐公式：

```text
行业调整后机会指数 = 基础机会指数 × 行业调整系数
```

进阶公式：

```text
行业调整系数 = 类目基础系数 + 机会修正项 - 风险修正项
```

建议总范围控制在：

```text
0.50–1.20
```

除非有极强证据，不建议低于 `0.40` 或高于 `1.20`。

---

## 2. 系数区间解释

| 系数范围 | 含义 | 使用判断 |
|---:|---|---|
| 1.10–1.20 | 类目环境友好，可以加分 | 需求增长、新品友好、低评论产品能卖、竞争分散 |
| 1.00 | 正常市场，不调整 | 没有明显加分或减分因素 |
| 0.85–0.95 | 轻度打折 | 有一定竞争，但仍然健康 |
| 0.70–0.80 | 明显打折 | 偏红海、同质化、广告压力较大 |
| 0.50–0.65 | 重度打折 | 高风险类目，强品牌 / 合规 / 退货 / 价格战风险 |
| <0.50 | 极高风险 | 一般不建议进入，除非有强供应链、品牌或产品创新 |

## 7. 推荐执行规则

### 7.1 默认规则

如果没有非常明确的类目证据，使用：

```text
行业调整系数 = 0.80
```

这是一个合理偏保守的默认值。

### 7.2 上限规则

普通市场不建议超过：

```text
1.10
```

只有在以下条件同时满足时，才考虑 `1.10–1.20`：

- 市场需求增长
- 低评论产品能卖
- 新品穿透率高
- TOP3 份额不高
- 产品痛点明确且可改良
- 价格带健康
- 合规和退货风险低

### 7.3 下限规则

如果出现以下任意两项，建议低于 `0.70`：

- 强同质化
- 低价竞争
- 强评论壁垒
- 高退货率
- 合规 / 认证风险
- TOP3 高度垄断
- 低评论产品基本无销量
- 广告 CPC / 客单价比值过高

## 8. 示例：Chocolate Molds

### 8.1 普通 Chocolate Molds

```text
基础类目：Kitchen & Dining
默认类目系数：0.80
```

风险修正：

| 因素 | 修正 |
|---|---:|
| 硅胶模具同质化 | -0.10 |
| 低客单价 | -0.05 |
| 季节性 | -0.05 |
| 普通款差异弱 | -0.05 |

理论计算：

```text
0.80 - 0.10 - 0.05 - 0.05 - 0.05 = 0.55
```

实际建议：

```text
0.65–0.75
```

原因：如果市场仍有低评论产品能卖，不能按极端高风险处理。

### 8.2 节日 / 造型差异化 Chocolate Molds

```text
基础类目系数：0.80
同质化风险：-0.05
季节性风险：-0.05
造型差异化：+0.05
节日需求明确：+0.05
```

合理范围：

```text
0.80–0.85
```

### 8.3 专业级 Polycarbonate Chocolate Molds

```text
基础类目系数：0.80
专业买家场景：+0.05–0.10
价格带更健康：+0.05
同质化风险较低：+0.00
```

合理范围：

```text
0.85–0.95
```

## 10. 使用建议

建议在 Codex 中按以下优先级执行：

1. 先识别 Amazon 大类目，读取大类目默认系数。
2. 如果能识别子类目，优先使用子类目范围。
3. 根据实际市场数据添加机会修正项。
4. 根据实际市场风险扣减风险修正项。
5. 最终结果限制在 `0.40–1.20` 之间。
6. 如果数据不足，使用默认保守值 `0.80`。
7. 如果是强合规、强侵权、高退货类目，即使基础机会指数高，也应优先降低系数。
