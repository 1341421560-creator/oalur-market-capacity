> 来源：第七章 专利与认证简述（视频课程）
> 整理时间：2026-06-20

## 一、专利

### 1. 专利分类

| 类型 | 说明 | 保护期 |
|---|---|---|
| **商标专利** | 文字商标、图形商标、图文组合、品牌Logo | 持续续展 |
| **发明专利** | 产品、方法或其改进的新技术方案 | 20年 |
| **实用新型专利** | 产品的形状、构造的新方案（"小发明"） | 10年 |
| **外观设计专利** | 产品的形状、图案、色彩结合的新设计 | 15年 |

**卖家高频遇到的侵权类型**：
- **商标侵权** → 多发于服装、玩具等非标品
- **外观侵权** → 多发于消费电子、厨房用具等带电/功能性产品

### 2. 侵权风险与预防

**风险来源**：
- 工厂将同一公模产品卖给多人，其中一人申请外观专利 → 其他卖家侵权
- 只做微调（改颜色、加Logo），未对形状做实质性改变

**预防措施**：
- **主动改进**：向工厂提出具体产品改进要求，与现有专利产生差异
- **申请自己的专利**：对公模产品做出显著差异改进后，申请外观专利形成壁垒
- **核心判定要素**：形状 > 图案 > 色彩。形状差异是最主要的判定依据
- **注意**：简单材质替换（塑料换金属）若造型不变，不算有效区别

### 3. 专利查询方法

**初步判断**：市场需求大但卖家数量异常少 → 很可能有专利风险

**查询渠道**：
- **商标**：美国专利商标局（USPTO）官网
- **外观专利**：Google 图片搜索"以图搜图" → 获取关键词 → 专利数据库检索
- **专业机构**：知识产权公司付费检索（最可靠）

## 二、认证

### 1. 检测分类
- 安全规范检测（安规）
- 化学测试
- 兼容性/性能测试

### 2. 主要市场认证要求

#### 美国市场

| 认证 | 适用范围 | 说明 |
|---|---|---|
| **FDA** | 食品、药品、医疗器械、化妆品 | 流程复杂，费用高（数千至数万美元），工厂有时可代办 |
| **CPC** | 儿童产品 | 基于CPSC认可实验室的CPSIA测试报告 |
| **CPSIA** | 儿童产品化学安全 | 邻苯二甲酸盐、重金属测试，费用相对不高 |

#### 欧洲市场

| 认证 | 适用范围 | 说明 |
|---|---|---|
| **CE** | 大部分产品（强制） | 进入欧洲市场的基本安全认证 |
| **WEEE** | 电子电气产品 | 需在销售国注册，可能需当地授权代表 |
| **LFGB** | 食品接触材料（德国） | 比一般EU食品级标准更严格 |
| **REACH/SVHC** | 化学品 | 注册、评估、授权和限制法规 |

#### 日本市场

| 认证 | 适用范围 | 说明 |
|---|---|---|
| **PSE（菱形）** | 特定电气用品 | **必须由日本本土授权机构完成**，中国检测公司多为中介 |
| **PSE（圆形）** | 非特定电气用品 | 相对宽松 |
| **电波法（技适标志）** | 无线通信设备（Wi-Fi、蓝牙） | 强制认证 |

### 3. 检测机构选择

**知名机构**：SGS、ITS天祥、BV、TÜV

**选择原则**：
1. 先明确目标平台和市场强制要求的具体标准
2. 核实机构是否拥有 CNAS、CMA 等认可资质
3. 可找大机构的授权服务商/代理商（更优惠、更快捷）
4. 专业机构会明确告知最低样品数量
5. ⚠️ 警惕"包过"承诺 → 不靠谱

## 三、决策清单

- [ ] 是否排查了商标侵权风险？
- [ ] 是否排查了外观专利风险（形状、图案、色彩）？
- [ ] 产品改进是否足以与现有专利区分？
- [ ] 是否考虑为自己的改进申请专利？
- [ ] 目标市场需要哪些强制认证？
- [ ] 工厂能提供哪些认证？哪些需要自行办理？
- [ ] 检测机构是否有正规资质？
- [ ] 是否避开了"包过"承诺的机构？

## 四、核心金句

1. "市场需求大但卖家少 → 大概率有专利风险"
2. "形状差异是最主要的外观专利判定依据"
3. "简单材质替换若造型不变，不算有效区别"
4. "菱形PSE必须由日本本土授权机构完成"
5. "警惕'包过'承诺，检测是严谨的科学过程"
