## 一、核心原则：利润优先

**利润高于一切。** 只有在利润有保障的前提下，才去考虑销量。

### 1.1 毛利率底线

- **毛利率基准线：35%**（不含产品开发和营销成本）
- 低于 35% 的产品，意义不大

### 1.2 为什么利润优先？——现金流陷阱

账面利润 ≠ 实际到手的现金流。

**案例对比：**

| | 产品A（高销量低利润） | 产品B（低销量高利润） |
|---|---|---|
| 日均单量 | 30 | 10 |
| 客单价 | $14.99 | $9.99 |
| 毛利率 | 25% | 30% |
| 成本/件 | $5 | $1.5 |
| 推广费/件 | $1.2 | $0.5 |
| 月销售额 | ~$13,491 | ~$2,997 |
| 月毛利 | ~$3,373 | ~$899 |

**表面看**：产品A利润远高于产品B。

**考虑现金流后**（备货周期3个月，备货量=月销量×1.5）：

| | 产品A | 产品B |
|---|---|---|
| 备货量 | 45单/天 | 15单/天 |
| 当月实际成本 | ($5+$1.2) × 45 × 30 ≈ $8,370 | ($1.5+$0.5) × 15 × 30 = $900 |
| 当月回款利润 | $3,373 | ~$899 |
| 现金流状态 | **严重紧张**，资金沉淀在库存 | **基本平衡**，压力小 |

### 1.3 现金流风险要点

- 单量增长 → 货款支出增长 → 资金沉淀在库存
- 必须考虑**工厂账期**能否覆盖库存回款周期
- 大件产品（海运）运输时间长，资金回转慢，前期投入巨大
- **中小卖家/创业者**：更应关注利润，避免低利润高销量的陷阱

## 二、市场需求量级判断：看大类排名

### 2.1 不靠谱的指标

| 指标 | 问题 | 参考价值 |
|---|---|---|
| **评论数（Reviews）** | 只体现市场成熟度，不等于需求量级；受上市时间、卖家数量影响 | ❌ 低 |
| **搜索结果数** | 不同工具数据差异大；翻页导致关键词变化，结果不准确 | ❌ 低 |
| **搜索量（Search Volume）** | 不同工具算法不同，量级差异巨大；含重复浏览，非独立用户 | ❌ 低 |

### 2.2 相对靠谱的指标

| 指标 | 说明 |
|---|---|
| **日均/月均销量** | 最直接反映收益，但工具估算准确率仅 75%-80% |
| **工具数据用途** | 只能用于**相对比较**（哪个量更大），不能作为**绝对依据** |

### 2.3 最靠谱的指标：大类排名（BSR）

**唯一可信赖且不会骗人的指标。** 平台给出的实实在在的数字。

- 每个大类排名区间对应一个相对稳定的日销量范围
- 排名本身变动频率不高
- **"模糊的准确"**：不需要知道排名10000确切等于30单还是40单，只需要知道排名10000的产品**日销量能否达到你的底线（如10单）**

## 三、市场容量评估方法论

### 3.1 分析页面选择

**推荐：最小类目页**（而非主关键词页）

- 找到标杆产品 → 跳转到其最小类目页面
- **优点**：
  - 节省时间，无需大量筛选关键词
  - 数据干净，受广告干扰小
  - 直接反映市场自然需求与销量排名关系

**不推荐**：主关键词页（混入非直接竞品或推广期产品，干扰判断）

### 3.2 排名区间划分与断层判断

**操作步骤**：
1. 对前100或200名产品进行排名区间划分
2. 区间**必须等宽**，可选**1000 / 1500 / 2000**三种间隔之一：
   - **1000间隔**（推荐精度最高）：0-1000, 1000-2000, 2000-3000, 3000-4000, 4000-5000, 5000-6000, 6000-7000, 7000-8000, 8000-9000, 9000-10000 ...
   - **1500间隔**（折中方案）：0-1500, 1500-3000, 3000-4500, 4500-6000, 6000-7500, 7500-9000, 9000-10500 ...
   - **2000间隔**（容量大时可用）：0-2000, 2000-4000, 4000-6000, 6000-8000, 8000-10000 ...
3. 统计每个区间的产品数量

**⚠️ 禁止不等宽区间**：
- ❌ **错误示例**：5000-10000（跨度 5000，将大量产品塞入一个区间，掩盖结构差异）
- ❌ **错误示例**：0-2000, 2000-4000, 4000-10000（底层密、中间跳、上层粗）
- ✅ 整条排名线从头到尾用**同一间隔宽度**，不允许中途换档

**粒度选择建议**：
- BSR 排名 20000 以内 → 用 **1000间隔**（更精细）
- BSR 排名 20000-50000 → 用 **1500或2000间隔**（避免区间过多）
- 选好后整条链统一，不混用

**观察要点**：
- **区间产品数量分布**：哪个区间最密集？头部是否垄断？
- **寻找"断层"**：某区间产品数为0 → 市场容量有限或竞争结构特殊
- **区分目标产品**：只统计与目标产品**功能高度一致**的SKU，排除同类目但功能不同的产品

### 3.3 各品类大类排名底线参考

> 排名在此之内，日销量大致能达到 10-15 单

| 品类 | 大类排名底线 |
|---|---|
| 美妆工具 | 8,000 - 10,000 |
| 厨房家居 | 10,000 |
| 宠物用品 | 25,000（市场体量大） |
| 鞋服 | 30,000 |
| 工具与家装 | 15,000 |
| 个人护理 | 10,000 |
| 消费电子 | 波动大，需具体分析 |

> 注意：此标准因人（目标单量）、因时（市场变化）、因品类（竞争格局）而异。

### 3.4 最终筛选逻辑（5步）

1. 找到目标产品所在的**最小类目**
2. 查看该类目下，排名在你的底线（如10,000名）以内的产品数量
3. 要求这个数量 **> 30个**（少于30个 → 市场容量可能不足）
4. 检查前100名产品中，**最后一名的排名是否远高于你的底线**
   - 例：前100名最后一名是6000名，底线是10000名 → 头部集中度高，进入机会小
5. 如果最小类目页不满足条件 → **跳转到主关键词页面**重新分析

## 四、关键决策清单

选品时逐条检查：

- [ ] 毛利率是否 ≥ 35%？
- [ ] 现金流是否健康？（备货成本 vs 回款利润是否平衡）
- [ ] 工厂账期能否覆盖库存回款周期？
- [ ] 大类排名底线是多少？（参考品类表格）
- [ ] 最小类目页中，底线内产品数量是否 > 30？
- [ ] 前100名最后一名排名是否远高于底线？（是 → 头部集中，慎入）
- [ ] 排名区间有无断层？（有 → 市场容量或结构有问题）
- [ ] 统计时是否只计算了功能高度一致的SKU？

## 五、核心金句

1. "利润高于一切，赚到高利润的钱才是真正的优势"
2. "账面利润 ≠ 实际到手的现金流"
3. "唯一可信赖且不会骗人的指标是大类排名"
4. "接受模糊的准确，不必追求销量数据的绝对精确"
5. "即使大市场红海，也可能存在细分蓝海"
