# 亚马逊选品规则：市调要素复盘与选品方法

> 来源：第十章 市调要素复盘与产品纳新（视频课程，共3部分）
> 整理时间：2026-06-20

## 一、市调五大要素复盘（完整判断顺序）

```
市场需求 → 毛利核定 → 竞争性判定 → 产品特色判定 → 进阶判定（生命周期）
```

### 1. 市场需求

**核心**：先确认大的市场需求，再做产品细分。

**判断方法**：
- 关键指标：**前10或前20名的单量总和** + **截止排名内的产品种数**
- 反映市场是"大池子"还是"小池子"

**日单量目标设定**：
- 高单价产品（$100-200）→ 日均 2-5 单即可
- 低单价产品 → 需要更高日单量支撑利润
- **计算逻辑**：目标日均10单，但市场前10名总共只能卖10单且第一名占大半 → 你做到10单的可能性极低

**局限性**：单纯靠市场需求淘汰产品比较困难，更多是基础过滤条件。

### 2. 毛利核定（最关键、最耗时）

**淘汰产品最多的环节**。

**正确方法**：
- 不要只参照卖得最好的1-2个产品核定毛利
- 对同一大类下的**不同产品形态**都要进行毛利核算
- 成本价主要参考 **1688**（价格弹性和供应商多样性优于阿里巴巴国际站）
- 核算时要考虑**包装费用**

### 3. 竞争性判定

**摒弃**复杂无标准指标（增长率、排名波动率），聚焦：

| 指标 | 判断方法 |
|---|---|
| **品牌占比** | 头部品牌集中还是分散？分散 → 新品牌机会大 |
| **单品占比** | 头部链接集中还是分散？ |

**新品关注**：
- 重点关注上架 6 个月内的新品
- 新品能冲到什么位置？是否进入你的目标销量区间？
- 大量新品涌入 → 可能是竞争激烈或产品处于爆发期

### 4. 产品特色判定

**四大维度**：单价、功能性、外观与颜色、组合

**新品特色分析**：
- 新品是老产品的**补充性配件**还是**差异化升级替代品**？
- 是否在保留核心价值的基础上放大了某个特色？

### 5. 进阶判定（生命周期）

**关键指标**：管理组合数量（变体数量）

**进入末期的信号**：
1. **整体排名下滑**：品类内大部分产品排名下降/低位震荡
2. **单价持续走低**：市场价格长期下行

> ⚠️ 核算毛利时，应选择**历史上维持时间最久的价格**作为参考，而非当前可能正在下跌的价格

## 二、非标品调研（特殊逻辑）

非标品（服装、玩具、装饰品）调研侧重点不同：

1. **产品分类**：确定细分品类（如女装→连衣裙→日常/通勤/度假风）
2. **毛利核算**：同样重要（不同面料/工艺成本差异大）
3. **关键词挖掘**：
   - 站内：核心词 → 长尾词、场景词
   - 站外：Pinterest、Instagram、Etsy 寻找设计趋势
4. **产品特色判定**：重点看**哪个设计元素被放大**
5. **简化环节**：可弱化竞争性和进阶性判定（非标品品牌集中度通常不高，更依赖审美判断）

**专利风险**：可通过以图搜图初步排查，但非标品元素更新快，风险相对可控。

## 三、选品方法（产品来源）

### 两大方向

| 方向 | 说明 | 适用场景 |
|---|---|---|
| **从品类到产品** | 先选有潜力的大品类，再筛选具体产品 | 更常见 |
| **从产品到品类** | 找到不错的产品，再观察其所在品类 | 需要一定经验 |

### 常见选品方法评析

| 方法 | 优点 | 缺点 | 适用人群 |
|---|---|---|---|
| **跟踪竞品** | 能发现已有验证的产品 | 需已在平台有建树，竞品上新规律性强 | 有经验卖家 |
| **站外灵感**（社交媒体） | 能提供创意 | 无法量化判断市场好坏，数据难迁移 | 有审美能力者 |
| **独立站借鉴** | 产品垂直化程度高 | 销量不透明，难以量化分析 | 不适合新手 |
| **量化工具筛选** | 可量化、可复制 | 数据有滞后性 | **无资源/无兴趣的新手** |

### 优秀品类的可量化特征

1. **品牌分散度高**：头部品牌份额不集中
2. **新品表现好**：新品在头部链接中占比高，且销量不错

### 工具筛选的有效指标

| 指标 | 是否有效 | 说明 |
|---|---|---|
| **价格** | ✅ 有效 | 新手建议 15-30 美金；有资源可试 80+ 美金（竞争可能更缓） |
| **月销量/BSR** | ✅ 有效 | 二者本质相同（反映需求），**二选一即可** |
| **评分** | ✅ 有效 | 可设 4 星以上 |
| **上架时间** | ✅ 有效 | 建议"上架1年以内"（太短市场稳定性未经检验） |
| **毛利率** | ❌ 无效 | 未确定产品前，工具计算的毛利率无参考意义 |
| **排名变化率** | ❌ 无效 | 数据波动大，不准确 |
| **变体数量** | ❌ 无效 | 不应作为筛选门槛 |
| **BSR+日销量同时限定** | ❌ 重复 | 逻辑重复，二选一 |

### 关键筛选技巧

- 保留 3-4 个核心参数即可（价格、销量、评分、上架时间）
- **重点观察**：筛选结果中是否存在**某一产品形态集中出现**（如6个产品中4个都是运动发带）→ 趋势信号
- 筛选后**必须回到手动市调流程**：产品分类 → 竞品分析 → 供应链挖掘

### 站内榜单（新品榜、飙升榜）

- **优点**：能发现爆发性产品
- **缺点**：数量少（100个）、无二级类目细分、需每天坚持查看
- **注意**：大类目（如"健康与家居"）门槛高、巨头垄断，参考意义不大

### 不同站点选品逻辑

**方法通用**，美国、欧洲、日本底层逻辑相同，区别在于产品呈现需适配不同人群/文化/习惯。

## 四、站外选品渠道与产品IDEA来源

### 核心前提
- **站内为主，站外为辅**：所有站外发现的灵感和产品，最终都必须回到亚马逊站内进行数据验证
- 站外主要用于**产品迭代**和寻找**新的灵感元素**（外观设计、图片风格、功能概念），而非主要的选品数据来源
- 站内基础未夯实前，不应急于转向站外

### 四大站外渠道

#### 1. 视频内容平台（TikTok、YouTube）
- **方法**：日常浏览关注品类关键词，让算法推送新奇产品视频
- **优点**：直观展示使用场景和卖点，比图文更生动；可通过播放量/点赞/评论判断热度
- **缺点**：无法精准数据化筛选，需回归站内验证
- **建议**：作为日常习惯，带着品类意识去发现

#### 2. 社交媒体与图文平台（Instagram、Pinterest）
- **方法**：订阅感兴趣的内容类别，平台推送相关图文
- **特点**：侧重**设计元素、美学风格和使用场景**，对非标品找设计灵感和款式迭代很有帮助
- **局限**：缺乏销售数据和关键词搜索功能，难以量化
- **应用**：确定品类后，寻找差异化外观和视觉灵感

#### 3. 独立站分析
- **工具**：Commerce Inspector，或谷歌搜索"关键词 + Shopify.com"
- **分析逻辑**：输入关键词/品牌 → 查看销售该产品的独立站列表及流量排名
- **作用**：发现亚马逊上尚未流行或表现形式不同的产品；观察广告素材和落地页设计
- **注意**：独立站选品逻辑与亚马逊不同，更侧重品牌故事和视觉冲击力，需结合供应链判断

#### 4. 众筹平台（Kickstarter、Indiegogo）
- **价值**：提供高创新性、概念性产品的早期样本；能看到市场验证数据（众筹金额和支持人数）
- **筛选要点**：
  1. 众筹金额与支持人数（超过 funding goal，如10万美元以上）
  2. 产品可落地性（标品vs非标品、供应链能否实现、开模成本）
  3. 解决的核心痛点（干什么用？为什么需要？比现有产品好在哪？）
- **风险**：
  - 产品可能停留在概念阶段，量产存在障碍
  - 可能存在**外观专利**风险，需排查和规避设计
  - 市场教育成本高，仅外观微创新无实质功能提升难以持久

### 站外选品核心理念

| 原则 | 说明 |
|---|---|
| **站内为主，站外为辅** | 所有灵感必须回站内数据验证 |
| **关注产品本质** | 始终围绕"用户为何购买"，分析主功能、次功能、使用场景、用户价值 |
| **供应链匹配** | 再好的创意也需要能生产，工厂型卖家可从熟悉的生产环节切入 |
| **避免盲目定制** | 非刚需低复购品类过度个性化 → 销量天花板极低，优先标品/半标品微创新 |
| **持续跟踪** | 保持对特定品类或渠道的持续关注，才能捕捉趋势 |

## 五、核心金句

1. "先确认大的市场需求，再做产品细分"
2. "毛利核定是淘汰产品最多的环节，也是最耗时的"
3. "不要只参照卖得最好的一两个产品核定毛利"
4. "核算毛利应选历史上维持时间最久的价格，而非当前可能下跌的价格"
5. "品牌分散度高 + 新品表现好 = 优秀品类"
6. "工具筛选后必须回到手动市调，快不了，是慢工出细活"
7. "有量变才有质变——持续大量地观察产品"
8. "站内分析是基石，站外探索是补充"
9. "选品本质是寻找'新的产品形式'来满足现有需求，而非寻找全新的产品"
10. "再好的产品创意，也需要能找到合适的供应商生产"
11. "对于非刚需低复购品类，过度追求个性化定制可能导致销量天花板极低"
